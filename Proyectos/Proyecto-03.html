PROJECT 03 · INFRASTRUCTURE LAB

Windows Server
Directory Services

Active Directory · DNS · Windows Server 2025

Laboratorio práctico de infraestructura Windows realizado utilizando VMware Workstation. El proyecto comprende la preparación de un entorno de red aislado, configuración de Windows Server, servicios de directorio, DNS y posterior integración de un equipo cliente Windows.

Ver repositorio ← Portafolio

01 / OVERVIEW

Descripción del laboratorio

El objetivo de este laboratorio es construir desde cero un entorno básico de infraestructura empresarial basado en Windows Server y Active Directory, documentando cada etapa mediante evidencias visuales.

🖥️

Servidor

Windows Server 2025 utilizado como servidor principal del laboratorio.

💻

Cliente

Windows 10 utilizado para validar la integración del equipo al dominio.

🧪

Virtualización

VMware Workstation con una red virtual aislada para realizar las pruebas.

02 / LAB ARCHITECTURE

Arquitectura del laboratorio

El entorno se mantiene aislado de la red física mediante una red virtual de laboratorio. Esto permite realizar configuraciones y pruebas sin afectar otros dispositivos.

``` 
┌──────────────────────────────────────┐
│        VMware Workstation            │
│                                      │
│            VMnet1                    │
│         Host-Only Network            │
│                 │                    │
│        ┌────────┴────────┐           │
│        │                 │           │
│        ▼                 ▼           │
│  Windows Server      Windows 10     │
│      2025               Client       │
│                                      │
│  Active Directory                    │
│  DNS                                  │
│  Domain Services                      │
│                                      │
└──────────────────────────────────────┘
```

Evidencias del laboratorio

Cada evidencia documenta una etapa concreta de la implementación. Las capturas muestran el proceso realizado directamente en las máquinas virtuales.

Preparación del entorno virtual

Creación de las máquinas virtuales necesarias para construir el laboratorio de Windows Server y Windows 10.

Qué demuestra: Preparación inicial de la infraestructura virtual utilizada para el laboratorio.

Configuración de red

Configuración de la red virtual utilizada para establecer comunicación entre el servidor y el cliente.

CAPTURA 02

Aquí colocaremos la captura de la configuración de red y las direcciones IP.

Instalación de Active Directory

Instalación del rol necesario para convertir Windows Server en controlador de dominio.

Configuración del dominio

DNS

CAPTURA 05
