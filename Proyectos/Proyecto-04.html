PROJECT 04 / INFRASTRUCTURE LAB

Infrastructure Monitoring

Linux · Node Exporter · Prometheus · Grafana

Laboratorio práctico de monitoreo de infraestructura desarrollado utilizando Node Exporter, Prometheus y Grafana. El objetivo fue implementar un entorno capaz de recopilar métricas de un sistema Linux, procesarlas mediante Prometheus y visualizarlas utilizando dashboards en Grafana.

Ver repositorio Volver al portafolio

/ OVERVIEW

Entorno del laboratorio

El laboratorio fue realizado en un entorno Linux utilizando herramientas de monitoreo orientadas a la recopilación, consulta y visualización de métricas del sistema. Node Exporter se utilizó para exponer las métricas del sistema, Prometheus para recopilarlas y Grafana para representarlas mediante dashboards.

/ VISUAL EVIDENCE

Implementación paso a paso

Las siguientes evidencias documentan las principales etapas realizadas durante la implementación del sistema de monitoreo, desde la preparación del entorno hasta la visualización final de las métricas en Grafana.

STEP 01

Verificación del sistema y red

Se realizó una verificación inicial del sistema Linux y de la configuración de red antes de comenzar la implementación del entorno de monitoreo. Esta comprobación permitió confirmar que el sistema estaba operativo y preparado para instalar los componentes del laboratorio.

Linux Network

STEP 02

Node Exporter

Se instaló y verificó Node Exporter, componente encargado de exponer métricas del sistema Linux para que Prometheus pueda recopilarlas. Esta etapa establece la fuente de métricas utilizada posteriormente por el sistema de monitoreo.

Node Exporter Metrics

STEP 03

Prometheus funcionando

Se verificó que Prometheus estuviera instalado y funcionando correctamente. Prometheus será responsable de consultar las métricas expuestas por Node Exporter y almacenarlas para su posterior consulta.

Prometheus Monitoring

STEP 04

Prometheus Server Ready

Se comprobó que el servidor Prometheus estuviera disponible y preparado para realizar consultas de las métricas recopiladas. Esta validación confirma que el servicio de monitoreo está operativo.

Prometheus Server Validation

STEP 05

Instalación de Grafana

Se instaló Grafana como plataforma de visualización para consultar y representar las métricas recopiladas por Prometheus. Grafana será utilizada posteriormente para construir y consultar el dashboard de monitoreo.

Grafana Installation

STEP 06

Problema de compatibilidad con Firefox

Durante la implementación se presentó un problema de compatibilidad al intentar acceder a Grafana mediante Firefox. La evidencia documenta el inconveniente encontrado durante la configuración del entorno.

Grafana Troubleshooting

STEP 07

Acceso a Grafana

Después de resolver el inconveniente inicial, se logró acceder correctamente a la interfaz de Grafana. Esto permitió continuar con la configuración de la plataforma de visualización.

Grafana Web Interface

STEP 08

Conexión de Grafana

Se inició la configuración de la conexión de Grafana con la fuente de datos que proporcionará las métricas del sistema de monitoreo.

Grafana Data Source

STEP 09

Agregar nueva conexión

Se seleccionó la opción para agregar una nueva fuente de datos dentro de Grafana. Esta configuración permite establecer el origen desde el cual Grafana consultará las métricas del sistema.

Grafana Data Source

STEP 10

Selección de Prometheus

Se seleccionó Prometheus como fuente de datos para Grafana. De esta manera, Grafana podrá consultar las métricas recopiladas por Prometheus y utilizarlas en los dashboards de monitoreo.

Prometheus Grafana

STEP 11

Configuración de la URL de Prometheus

Se configuró en Grafana la dirección del servidor Prometheus para establecer la comunicación entre ambas plataformas. Esta configuración permite que Grafana consulte las métricas almacenadas por Prometheus.

Prometheus URL Grafana Data Source

STEP 12

Dashboard final de monitoreo

Finalmente se importó y configuró el dashboard Node Exporter Full en Grafana. El dashboard permite visualizar diferentes métricas relacionadas con el funcionamiento y utilización de los recursos del sistema Linux. Esta evidencia representa el resultado visual de la integración entre Node Exporter, Prometheus y Grafana.

Grafana Dashboard Node Exporter Full
