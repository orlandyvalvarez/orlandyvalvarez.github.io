PROYECTO 05

IT Service Desk & Ticketing

Implementación de una plataforma de mesa de ayuda utilizando GLPI 11 sobre Linux Mint para gestionar solicitudes de soporte, categorías ITIL, seguimiento, soluciones y cierre de incidencias.

Resumen del laboratorio

Sistema Linux Mint XFCE
Aplicación GLPI 11
Servidor web Apache2
Lenguaje PHP
Base de datos MariaDB
Base de datos GLPI glpidb
Gestión ITIL / Service Desk
Flujo probado Solicitud → Seguimiento → Solución → Cierre

Componentes del laboratorio

Linux Mint

Sistema operativo utilizado como entorno principal para realizar el laboratorio.

Apache2

Servidor web utilizado para publicar y ejecutar la plataforma GLPI.

PHP

Entorno necesario para ejecutar GLPI y sus componentes web.

GLPI 11

Plataforma utilizada para administrar solicitudes y operaciones del Service Desk.

MariaDB

Sistema de base de datos utilizado para almacenar la información de GLPI.

Tecnologías utilizadas

Linux Mint GLPI 11 Apache2 PHP MariaDB ITIL Service Desk Ticketing Incident Management Linux Administration
