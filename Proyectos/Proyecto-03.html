Laboratorio práctico de infraestructura Windows desarrollado con Windows Server 2025, Active Directory, DNS, DHCP y Group Policy utilizando VMware Workstation.

Windows Server 2025 Active Directory DNS DHCP Group Policy VMware
01 / OBJETIVO

¿Qué construí?

Construí un laboratorio de infraestructura Windows completamente virtualizado. El objetivo fue implementar un dominio utilizando Windows Server 2025 y conectar un cliente Windows 10 Pro al dominio.

Durante el laboratorio configuré Active Directory, DNS, DHCP y Group Policy y posteriormente realicé diferentes pruebas para comprobar que los servicios funcionaban correctamente.

02 / ARQUITECTURA

Arquitectura del laboratorio

El laboratorio utiliza una red VMware VMnet1 Host-Only para mantener las máquinas virtuales aisladas de la red física.

04 / RESULTADO

Resultado final

El laboratorio quedó funcionando como un entorno Windows basado en dominio. Windows Server 2025 proporciona los servicios principales de infraestructura y Windows 10 Pro funciona como cliente del dominio.

Las pruebas realizadas permitieron comprobar conectividad, resolución DNS, asignación DHCP, autenticación mediante Active Directory y aplicación de políticas de grupo.
