Proyecto 05: laboratorio de infraestructura

IT Service Desk & Ticketing

  • GLPI
  • ITSM
  • Linux
  • Apache
  • PHP
  • MariaDB

Laboratorio práctico de IT Service Desk desarrollado utilizando GLPI 11 sobre Linux Mint. El objetivo fue implementar una plataforma de mesa de ayuda funcional para gestionar solicitudes de soporte, clasificación de incidencias, seguimiento, solución y cierre de peticiones.

Ver repositorio Volver al portafolio

Entorno del laboratorio

El laboratorio fue construido directamente sobre Linux Mint utilizando una instalación local de Apache, PHP y MariaDB. Sobre esta infraestructura se implementó GLPI 11 para simular un entorno básico de mesa de ayuda y gestión de incidencias.

Resultado del laboratorio

IT Service Desk funcional

El laboratorio quedó funcionando como una plataforma básica de mesa de ayuda utilizando GLPI 11 sobre Linux Mint. Se implementaron los componentes necesarios de infraestructura, se configuró la base de datos y se validó el flujo completo de una solicitud de soporte.

La prueba permitió recorrer el ciclo de una incidencia desde su creación hasta el registro de la solución y posterior cierre de la petición.
