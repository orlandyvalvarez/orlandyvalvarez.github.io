PROJECT 03 / INFRASTRUCTURE LAB

Windows Server Directory Services

Active Directory · DNS · DHCP · Group Policy

Laboratorio práctico de infraestructura Windows desarrollado utilizando VMware Workstation, Windows Server 2025 y Windows 10 Pro. El objetivo fue construir un entorno de dominio funcional, implementar servicios de infraestructura y validar su funcionamiento mediante pruebas reales.

04 / VISUAL EVIDENCE

Implementación paso a paso

Las siguientes evidencias documentan las principales etapas de construcción, configuración y validación del laboratorio.

EVIDENCE 01

VMware VMnet1 — Red aislada

Configuración del entorno virtual utilizando VMware VMnet1 en modo Host-Only. Las máquinas virtuales utilizan esta red para comunicarse entre sí sin depender de la red física.

VMware / VMnet1 192.168.78.0/24

EVIDENCE 02

Configuración IP del servidor

Se configuró el servidor Windows Server 2025 con una dirección IPv4 estática para mantener una dirección conocida dentro de la infraestructura del dominio.

DC01-LAB-WS 192.168.78.10

EVIDENCE 03

Active Directory Domain Services

Implementación del dominio Active Directory alvarez.local y estructura organizativa con las unidades IT, HR y Ventas. También se configuraron grupos de seguridad y usuarios de dominio.

Active Directory alvarez.local

EVIDENCE 04

Configuración DNS

DNS fue implementado como parte de la infraestructura del controlador de dominio. El cliente utiliza el servidor 192.168.78.10 como DNS para resolver el dominio y el nombre del controlador de dominio.

DNS alvarez.local

EVIDENCE 05

Servidor DHCP

Se instaló y configuró DHCP en Windows Server mediante el ámbito DHCP-LAB. El rango disponible es 192.168.78.100 - 192.168.78.200. El servidor también entrega la configuración DNS correspondiente al dominio.

DHCP-LAB 192.168.78.100 - 200

EVIDENCE 06

Windows 10 unido al dominio

El equipo Windows 10 Pro fue integrado al dominio alvarez.local y configurado como WIN10-CLIENTE01. Posteriormente se comprobó el inicio de sesión utilizando una cuenta de dominio.

Windows 10 Pro ALVAREZ\orlandy

EVIDENCE 07

Cliente obteniendo IP mediante DHCP

El cliente fue configurado para obtener automáticamente su configuración de red. La asignación fue comprobada mediante ipconfig /all. El cliente recibió la dirección 192.168.78.101.

DHCP Client 192.168.78.101

EVIDENCE 08

Creación de Group Policy

Se creó la política GPO-IT-Restriccion-Panel mediante Group Policy Management y se vinculó a la OU IT. La configuración corresponde a las políticas administrativas del Panel de control.

Group Policy OU: IT

EVIDENCE 09

Actualización de políticas

Después de configurar la GPO se ejecutó gpupdate /force en el cliente Windows 10 para forzar la actualización de las directivas.

gpupdate /force Policy Refresh

EVIDENCE 10

Validación de la GPO aplicada

Finalmente se utilizó gpresult /r para comprobar que la política GPO-IT-Restriccion-Panel fue aplicada correctamente al usuario del dominio. La política implementada bloquea el acceso al Panel de control y a Configuración del PC.

gpresult /r GPO Applied

05 / VALIDATION

Pruebas realizadas

Además de las configuraciones visuales, el laboratorio fue validado mediante comandos de Windows para comprobar conectividad, DNS, autenticación, DHCP y aplicación de políticas.

06 / FINAL RESULT

Resultado del laboratorio

Infraestructura Windows funcional

El laboratorio quedó funcionando como un entorno de infraestructura Windows basado en dominio. Windows Server 2025 opera como controlador de dominio y proporciona los servicios de Active Directory, DNS y DHCP.

El equipo Windows 10 Pro fue integrado correctamente al dominio alvarez.local, obtiene su configuración de red mediante DHCP y utiliza el controlador de dominio como servidor DNS.

También se implementó una política de grupo vinculada a la OU IT y se comprobó mediante gpresult que la política fue recibida correctamente por el usuario de prueba.
