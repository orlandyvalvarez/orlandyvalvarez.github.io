PROJECT 03 / INFRASTRUCTURE LAB

Windows Server Directory Services

Active Directory · DNS · DHCP · Group Policy

Laboratorio práctico de infraestructura Windows desarrollado utilizando VMware Workstation, Windows Server 2025 y Windows 10 Pro. El objetivo fue construir un entorno de dominio funcional, implementar servicios de infraestructura y validar su funcionamiento mediante pruebas reales.

06 / FINAL RESULT

Resultado del laboratorio

Infraestructura Windows funcional

El laboratorio quedó funcionando como un entorno de infraestructura Windows basado en dominio. Windows Server 2025 funciona como controlador de dominio y proporciona los servicios de Active Directory, DNS y DHCP.

El equipo Windows 10 Pro fue integrado correctamente al dominio alvarez.local y se realizaron pruebas de conectividad, autenticación y configuración de red.

También se implementó una política de grupo para restringir el acceso al Panel de control y Configuración, validando posteriormente su aplicación mediante las herramientas de Windows.
