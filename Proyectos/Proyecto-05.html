PROYECTO 05

IT Service Desk & Ticketing

Implementación de una plataforma de mesa de ayuda utilizando GLPI 11 sobre Linux Mint para gestionar solicitudes de soporte, categorías ITIL, seguimiento, soluciones y cierre de incidencias.

Resumen del laboratorio

Sistema Linux Mint XFCE
Aplicación GLPI 11
Servidor web Apache2
Lenguaje PHP
Base de datos MariaDB
Base de datos GLPI glpidb
Gestión ITIL / Service Desk
Flujo probado Solicitud → Solución → Cierre

Arquitectura

Linux Mint

Sistema operativo utilizado para el laboratorio.

Apache2

Servidor web encargado de publicar GLPI.

PHP

Entorno requerido para ejecutar GLPI.

GLPI 11

Plataforma utilizada para gestionar el Service Desk.

MariaDB

Base de datos utilizada por GLPI.

Tecnologías utilizadas

Linux Mint GLPI 11 Apache2 PHP MariaDB MySQL ITIL Service Desk Ticketing Incident Management Linux Administration
